# 🧠 Previsão de Score de Crédito com Machine Learning

Este projeto utiliza técnicas de Machine Learning para prever o score de crédito de clientes com base em dados históricos.

Foram utilizados algoritmos de classificação para identificar o perfil de risco dos clientes e realizar previsões em novos dados.

---

## 🚀 Objetivo

Criar um modelo capaz de classificar clientes em categorias de risco de crédito com base em variáveis comportamentais e financeiras.

---

## 🛠️ Tecnologias utilizadas

- Python
- Pandas
- Scikit-learn
- Random Forest
- KNN (K-Nearest Neighbors)
- LabelEncoder

---

## 🧠 Etapas do projeto

1. Leitura e análise da base de dados
2. Pré-processamento de variáveis categóricas
3. Separação entre dados de treino e teste
4. Treinamento dos modelos:
   - Random Forest
   - KNN
5. Avaliação de desempenho (accuracy)
6. Previsão de novos clientes

---

## 📊 Algoritmos utilizados

- 🌳 Random Forest Classifier
- 📍 K-Nearest Neighbors

---

## 📈 Métrica utilizada

- Accuracy Score (precisão do modelo)
